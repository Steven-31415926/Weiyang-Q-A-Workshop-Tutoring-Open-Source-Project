# Weiyang Q&A Workshop Tutoring Open-Source Project

## 中文

THU未央书院答疑坊开源资料库，现主要收录Steven在未央书院答疑坊的小班辅导讲义资料。

## English

Open-source archive of the Q&A Workshop at Weiyang College, Tsinghua University (THU). It currently mainly collects the small-group tutoring notes Steven prepared for the Weiyang College Q&A Workshop.

## 目录 / Contents

### 基础物理学 1 / Fundamental Physics 1

力学、振动与波、相对论相关的小班讲义。

Small-group notes on mechanics, oscillations and waves, and relativity.

- `有心力场.pdf`
- `机械波.pdf`
- `简正模.pdf`
- `相对论.pdf`
- `基物一期中小班辅导csm(4).pdf`

### 基础物理学 3 / Fundamental Physics 3

电磁学小班辅导讲义，含 XeLaTeX 源码。在 `基础物理学3-电磁学小班辅导` 目录运行 `.\build.ps1` 可重新编译，编译结果为 `基础物理学3_电磁学小班辅导.pdf`。

Electromagnetism small-group notes, including the XeLaTeX source. From `基础物理学3-电磁学小班辅导`, run `.\build.ps1` to recompile. The compiled file is `基础物理学3_电磁学小班辅导.pdf`.
